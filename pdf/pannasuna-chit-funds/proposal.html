Android + iOS App & Website
01 Overview

Complete digital infrastructure for Pannasuna Chit Funds. A mobile app (Android + iOS) and a full website allowing enrolled members to check chit status, view payment schedules, track their group, and access complete account history — all connected to a central database hosted on Hyperwrike's GPU-enabled dedicated server.

02 Deliverables
App — Android + iOS
  1. Member login — secure, OTP-based
  2. Chit dashboard — enrolled chits, group status, next draw
  3. Full payment history — paid, pending, upcoming
  4. Chit auction & winner history
  5. Notifications — reminders, results, announcements
  6. Document download — receipts, certificates
  7. Contact / support screen
Website
  1. Public landing — about, how it works, enroll
  2. Member portal — full feature parity with app
  3. Admin dashboard — groups, members, payments, reports
  4. SEO-optimised pages for discovery
Backend / Database
  • GPU-enabled dedicated server (Hyperwrike)
  • Member DB — enrollment, groups, payments
  • Secure shared API · auto reminder engine · backup & recovery
